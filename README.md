# Ordain

Ordain is an open commissioning platform for creative work, built on Bitcoin's Lightning Network. Patrons post briefs with commissions, creators submit work, stakeholders vote, and winners are paid in bitcoin over Lightning.

**Live site:** https://ordain.art

## Status

This repository contains the current Ordain website (static HTML and CSS). Lightning payment integration is in active development with a contracted developer. The site launched in February 2026 with five founding commissions.
